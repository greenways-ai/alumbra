# Integrated renderer Workspace

This complete Hodos Showcase coordinates the installed Renderer Catalog, a live Alumbra viewport, Code, Execution, Problems and REPL as separate authorities.

The lifecycle story proves that:

- switching activities destroys the previous viewport before creating the next;
- ordinary model updates preserve the same engine, session and canonical world;
- hiding the World surface suspends rendering;
- returning resumes the same world and engine;
- wide and compact layouts project only bounded semantic evidence.

The Workspace contains no PlayCanvas constructors, project paths, chunks, mesh buffers, shader source, callbacks, capability grants or arbitrary source/test expressions.
