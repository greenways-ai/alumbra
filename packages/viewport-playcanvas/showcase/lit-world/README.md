# Live lit-world viewport

This complete Showcase project describes the live browser proof for the merged
Alumbra lighting stack.

The browser host owns one deterministic two-chunk cave fixture spanning
`-1,0,0` and `0,0,0`. A boundary lamp propagates emitted light into the adjacent
chunk through Engine fields, renderer-owned copied snapshots, light-aware greedy
meshes and PlayCanvas vertex colours.

The Hara source remains descriptive. It exposes package identities, authority
boundaries and bounded expected evidence; it does not contain chunks, dense light
fields, vertex channels, callbacks, PlayCanvas objects or storage capabilities.
